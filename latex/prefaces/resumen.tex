  \noindent{\textbf{Resumen}}\\
\end{center}

Este Trabajo Final de Máster desarrolla una solución integral para estimar y explicar la volatilidad implícita de opciones sobre el IBEX. A partir de operaciones reales, contratos, futuros subyacentes y series de tipos EONIA/\texteuro{}STR, se construye una base de volatilidad implícita mediante validaciones financieras e inversión numérica del modelo Black-76. Sobre esta base se entrenan varias familias de modelos de regresión: regresión lineal, Random Forest, XGBoost, redes neuronales y una arquitectura clásica \emph{quantum inspired}.

La contribución principal no es únicamente predictiva. El proyecto convierte los modelos en artefactos explicables y consultables mediante un dashboard y una API FastAPI. La explicabilidad se aborda con SHAP global y local, superficies de volatilidad, curvas ICE y ALE, árboles surrogate, regresión simbólica, vecinos históricos y diagnósticos de residuales. Esta combinación permite evaluar precisión, robustez, coherencia financiera y soporte local de las predicciones.

La metodología incorpora splits temporales, control de contratos compartidos, k-folds temporales y métricas compuestas que penalizan inestabilidad y sobreajuste. La memoria deja preparada la sección de resultados para incorporar las métricas definitivas, comparar entrenamiento estándar frente a progressive ATM, seleccionar el mejor modelo y analizar con detalle las vistas del dashboard. El resultado es una arquitectura reproducible orientada a model validation, auditoría interna y uso operativo en entornos financieros.
